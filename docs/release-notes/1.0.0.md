FlipFlex is a Plex client for the TCL 4058G flip phone. No touchscreen, no
scrolling artwork — a text list you drive with the keypad.

- **Watch your Plex library on the flip phone.** Sign in, pick a server, browse
  by library, and play. Everything is converted by your server first, so every
  file behaves the same way.
- **Resume where you left off**, on this phone or any other Plex client.
- **Search from anywhere** with the green call key.
- **Download episodes and films to the phone** and watch them with both radios
  switched off — seeking included.
- **Subtitles, audio tracks and quality** are all pickable per item.
- **A first-run tour** that teaches the keypad on a drawing of the phone.
